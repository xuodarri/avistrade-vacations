# Отпуска без ручных сверок — прототип для ООО «Авистрейд»

Тестовое задание: автоматизировать сбор пожеланий по отпускам, проверку по регламенту компании и ТК РБ,
поиск пересечений и согласование, оставив за HR управление правилами и исключениями.

Описание решения, альтернативы, развитие и вопросы к компании — на странице «О решении» (`/about`) внутри прототипа:
https://avistrade-vacations.onrender.com/about

Все люди и данные в прототипе вымышленные.

## Запустить у себя

Нужен Node.js 24.

```bash
cd web
npm install
npm run dev
```

Откроется на http://localhost:3400. База SQLite создаётся с демо-данными при первом запросе.
Тесты движка правил и базы — `npm test`. Устройство кода — [`web/README.md`](web/README.md), выкладка — [`web/DEPLOY.md`](web/DEPLOY.md).
