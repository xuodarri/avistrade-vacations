# Отпуска 2027 — веб-приложение

Next.js 16 (App Router, TypeScript), Tailwind v4, Node 24, SQLite через встроенный `node:sqlite`.

## Запуск

```bash
npm install
npm run dev
```

Порт 3400. База — `data/vacations.db`, создаётся и заполняется демо-данными при первом запросе.
Путь можно задать переменной `DB_PATH`. «Сегодня» для проверок правил фиксируется `DEMO_TODAY` (например, `2026-10-27`).

```bash
npm test
```

## Устройство

| Где | Что |
|---|---|
| `src/domain/` | Движок правил: регламент компании и нормы ТК РБ, уровни «нельзя / нужно исключение / предупреждение», подбор свободных окон. Не зависит от интерфейса и базы, покрыт тестами |
| `src/server/db/` | Схема, миграции, демо-данные, репозитории. В базу ходят только через `repo.ts` |
| `src/server/actions/` | Серверные действия экранов: план сотрудника, очередь руководителя, Гант и решения РО1, правила, сбор графика |
| `src/server/audit.ts` | Журнал действий: кто, когда, было → стало — в той же транзакции, что и изменение |
| `src/components/kit/` | Набор интерфейсных элементов, описание — `kit/README.md`, витрина — `/kit` |
| `src/app/` | Экраны: `/me` сотрудник, `/team` руководитель, `/hr` Гант, `/hr/rules`, `/hr/log`, `/hr/dashboard`, `/hr/people`, `/about` |
