# Выкладка

Приложение собирается из `Dockerfile` (Node 24, Next.js standalone). База SQLite — один файл, путь задаёт `DB_PATH`.
Если файла нет, первый запрос создаёт схему и заполняет её демо-данными.

## Render (бесплатный тариф)

В корне репозитория лежит `render.yaml`: New → Blueprint → репозиторий. На бесплатном тарифе нет постоянного диска,
поэтому база живёт в `/tmp` и возвращается к демо-данным, когда сервис засыпает после 15 минут без запросов.

## Свой сервер

```bash
docker build -t avistrade-vacations .
```

```bash
docker run -d -p 3000:3000 -v /srv/avistrade:/data -e DEMO_TODAY=2026-10-27 avistrade-vacations
```

База — `/data/vacations.db` на примонтированной папке, переживает перезапуск и обновление.

## Переменные

| Переменная | Значение | Зачем |
|---|---|---|
| `DB_PATH` | `/data/vacations.db` | путь к файлу базы |
| `DEMO_TODAY` | `2026-10-27` | «сегодня» для проверок правил; без неё — текущая дата по Минску |
| `NEXT_PUBLIC_DEMO` | `1` | демо-переключатель ролей и сброс данных; вшивается при сборке, в `Dockerfile` по умолчанию `1` |
| `PORT` | `3000` | порт сервера |
