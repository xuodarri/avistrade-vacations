# tour — «Помощь»: пошаговый тур по экрану

- `HelpButton` (`import { HelpButton } from "@/components/tour"`) — кнопка «?» в шапке, `access` — права текущего пользователя.
  Открывает тур текущего экрана; на экранах без тура её нет. На /me при первом заходе рядом пилюля «Как пользоваться?».
- `TourRunner` — движок: затемнение с вырезом (радиус элемента + 6), карточка kit рядом на `@floating-ui/react`,
  переворот у края, плавная прокрутка к элементу, клавиши → / Enter / ← / Esc, `prefers-reduced-motion`.
- `steps.ts` — шаги по экранам (данные). Шаг без элемента на странице пропускается; шаг с `reveal` сам нажимает
  на кнопку, которая открывает цель (панель заявки на /hr), и закрывает её Esc, когда тур уходит назад или закрывается.
- «Пройден» — `localStorage["tour:v1:<экран>:<роль>"]`. Сбросить: удалить ключ.
- Демо движка — http://localhost:3400/tour-demo.

## Якоря — `data-tour="…"` на элементах экранов

Элемент должен быть виден (не нулевого размера, не `opacity: 0`). Если у обёртки нет скругления, тур возьмёт радиус
единственного ребёнка того же размера.
